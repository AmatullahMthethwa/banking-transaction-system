# Banking Transaction System

A full-stack banking transaction system built with Spring Boot and PostgreSQL.

## Features

- User Registration
- User Authentication (JWT)
- Account Creation
- Account Management
- Deposits
- Withdrawals
- Transfers
- Transaction History
- Audit Logging
- REST APIs
- Frontend Dashboard

## Technology Stack

### Backend
- Java 21
- Spring Boot
- Spring Security
- JWT
- PostgreSQL
- Docker
- Swagger
- JUnit

### Database
- PostgreSQL

### Frontend
- React
- Next.js
- TypeScript
- Tailwind CSS
- Axios or Fetch API

### DevOps
- Docker
- Docker Compose
