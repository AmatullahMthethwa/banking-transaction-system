# Banking Transaction System

A full-stack banking transaction system built with Spring Boot and PostgreSQL.

## Features

- User Registration
- User Authentication (JWT)
- Account Creation
- Account Management
- Deposits
- Withdrawals
- Transfers
- Transaction History
- Audit Logging
- REST APIs
- Frontend Dashboard

## Technology Stack

### Backend
- Java
- Spring Boot
- Spring Security
- JWT
- Maven

### Database
- PostgreSQL

### Frontend
- React (planned)

### DevOps
- Docker
- Docker Compose
